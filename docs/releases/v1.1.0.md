# GA-Hub v1.1.0

## Release-based self-update (Windows x64)
- Settings > Updates checks the public Luna-dash/GA-Hub stable GitHub Release without a GitHub login.
- Downloads the official ZIP and SHA256SUMS, validates version, platform, archive paths, sizes and executable hashes before preparing.
- Bundles an independent update helper and registers its per-user on-demand scheduled task on first use (no administrator rights required).
- Preflight remains mandatory. Only after independent-worker readiness and explicit confirmation does the countdown switch the desktop. Health verification and rollback remain in place.
- Original desktop shortcuts follow the last completed, hash-verified version; health/rollback launches bypass redirection.

## First deployment
Download `GA-Hub-1.1.0-windows-x64.zip`, extract **all** files into a writable local directory, and launch `ga-hub-desktop.exe`. Keep both other EXEs and build-info.json together. Configure the GA core checkout/interpreter as before; this package bundles the Hub backend, not GA core.

Future stable releases use the same Updates workflow. Windows Task Scheduler must be available, the same Windows user must own the installation/data, and GitHub release endpoints must be reachable. No running installation is overwritten. Back up data before updating. SHA-256 detects corruption; publisher trust comes from HTTPS and the fixed GitHub repository, not a separate signing key.
