# GA-Hub v1.1.2

## GitHub Release self-update (Windows x64)
- Settings > Updates checks stable releases from the public `Luna-dash/GA-Hub` repository without a GitHub login.
- Downloads the official ZIP and SHA256SUMS, validates stable version, platform, archive paths, sizes and executable hashes before preparation.
- Includes the independent update helper; first use registers its per-user on-demand Windows scheduled task without administrator rights.
- Mandatory preflight and independent-worker readiness precede explicit user confirmation. Health checks and rollback protect the switch; existing shortcuts follow the last completed, hash-verified version.

## Build fixes
- Standard CPython builds no longer require Conda-only runtime DLLs; Conda builds retain their DLL validation.
- Portable builds explicitly stage the current sidecar alongside the desktop and update helper, retaining freshness guards and frozen-runtime selftests.
- Supersedes v1.1.0 and v1.1.1, whose cloud builds failed before publishing Release assets. The corrected main-branch cloud build passed before this release was tagged.

## First deployment
Download `GA-Hub-1.1.2-windows-x64.zip`, extract **all** files into a writable local directory, and run `ga-hub-desktop.exe`. Keep the three EXEs and JSON metadata together. Configure the GA core checkout/interpreter as before: this package bundles the Hub backend, not GA core.

For subsequent stable releases, open Settings > Updates, check, download/prepare, run preflight, and explicitly confirm the switch. Windows Task Scheduler must be available, installation/data must belong to the same Windows user, and GitHub release endpoints must be reachable. Back up data before updates. Running installations are not overwritten.

SHA-256 detects corruption; publisher trust comes from HTTPS and the pinned GitHub repository, not an independent signing key. Real cross-machine installation/switch testing has not been performed on the user's other machine.
