# GA-Hub v1.1.4

## 会话管理
- 项目标题使用带边框的分组栏，会话改为无边框紧凑行，强化项目与会话的层级。
- 默认项目名称隐藏末尾的八位内部编码，自定义名称保持原样。
- 会话数量常显于项目标题行；双箭头图标支持展开全部、恢复最近三条，并可从完全折叠状态直接展开全部。

## 桌面图标
- 调整多分辨率 ICO 的帧顺序，避免桌面框架将 16px 图标放大后用于窗口及任务栏，保留完整尺寸集。

## 功能清理
- 移除模型指纹功能及对应界面、客户端接口、服务端路由和文档。
- 保留常规模型选择、聊天和会话管理功能。

## 安装与更新
下载 `GA-Hub-1.1.4-windows-x64.zip`，完整解压后运行 `ga-hub-desktop.exe`，保持桌面程序、后端、更新助手及元数据在同一目录。已有正式版可在「设置 → 更新」检查并准备此版本，经预检及明确确认后切换。

发布包附带构建信息和 SHA-256 校验清单，继续使用 GitHub 稳定 Release 自更新机制。
