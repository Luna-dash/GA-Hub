# GA-Hub v1.1.3

## Self-contained message presentation
- Bundle the build machine's matching Node 20+ runtime, official LICENSE and version/architecture/SHA-256 metadata with the Hub backend.
- Frozen releases use only their bundled Node, never a Node installation from the user's PATH. GA core setup still requires its configured checkout and Python interpreter.
- Frozen runtime selftests now execute a real compact-message conversion and close the worker; missing or broken presentation dependencies fail the build.

## Packaging cleanup
- Stage only the four runtime Nova/gateway Python assets; omit standalone installation scripts, tests, documentation and interpreter caches.
- Collect server modules without duplicating the server source tree as data, while retaining the message-presentation worker explicitly.
- Keep existing third-party dependency collection until frozen-runtime evidence supports further exclusions.

## Deployment and updates
Download `GA-Hub-1.1.3-windows-x64.zip`, extract every file together and launch `ga-hub-desktop.exe`. Keep the desktop, sidecar, update helper and metadata together. Existing v1.1.2 installations can use Settings > Updates to check, prepare, preflight and explicitly confirm this stable release. Back up data before switching; running turns may be interrupted.

SHA-256 verifies integrity; publisher trust remains HTTPS plus the pinned official GitHub repository, not an independent signing key. Cross-machine switching on the user's other machine is not claimed as tested.
