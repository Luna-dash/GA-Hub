# GA-Hub v1.2.0

## Agy 聊天

- GA-Hub 内置 Agy ACP 集成，可直接驱动本机安装的官方 Agy CLI，无需另外部署网关。支持账号与模型切换、思考等级、会话管理、附件和任务进度。
- 改善流式回复、运行中追加指令与停止、用量统计和异常恢复。若导航栏未显示 Agy，可在设置中启用该页面。

## 会话与文件

- 改进长会话滚动、轮次导航及历史加载；增加聊天文件中转箱和文件引用操作。
- 改进定时消息及中断恢复、桌面启动与更新预检，并加强本地文件访问约束。

## Windows x64 安装与升级

1. 下载 `GA-Hub-1.2.0-windows-x64.zip`，按需用 `SHA256SUMS.txt` 核对 ZIP。完整解压，保持三个 EXE 和元数据在同一目录，运行 `ga-hub-desktop.exe`。
2. 首次在新电脑运行时，按应用提示选择本机的 GenericAgent（GA）目录及其 Python 解释器。GA 核心和它的运行环境不包含在 ZIP 中。
3. 要使用 Agy，请在目标电脑单独安装官方 `agy` CLI，在该电脑上完成账号登录，再从 Hub 的 Agy 页面发一条消息确认连接。ZIP 不包含 Agy CLI、账号或登录凭据。

已有支持在线更新的版本，可在「设置 → 更新」中检查新版，通过预检后确认升级。
