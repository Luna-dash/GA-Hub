# Gyra v1.3.0（原 GA-Hub）

## Agy 与远程连接

- 「用量统计」现在汇总 GA 和 Agy 的 Token；Agy 的官方剩余额度仍在会话页标题栏单独查看，不等同于本地用量。
- Agy 支持持久化后续消息队列、会话未读提醒和归档保留策略。通过 Nova 连接 Agy 时，可使用附件、模型设置、会话管理和离线历史。

## 聊天与界面

- 更新产品显示名称为 Gyra，改进侧栏、会话导航、长提示词折叠和高对比度主题。
- 改进桌面启动和资源占用；更新助手改为独立的 Rust 程序。

## Windows x64 安装与升级

1. 下载 `GA-Hub-1.3.0-windows-x64.zip`，可用 `SHA256SUMS.txt` 校验。完整解压，保留 `sidecar/` 目录及同目录的更新助手和元数据，再运行 `ga-hub-desktop.exe`；不要只替换主 EXE。
2. 首次安装时按提示选择本机的 GenericAgent（GA）目录和 Python 解释器。使用 Agy 还需在本机安装并登录官方 `agy` CLI。安装包不包含 GA 核心、Agy CLI 或账号凭据。
3. 已支持在线更新的版本可在「设置 → 更新」中检查新版，下载校验通过后点击「立即重启并更新」一键切换（新版本健康检查失败会自动回退）。
