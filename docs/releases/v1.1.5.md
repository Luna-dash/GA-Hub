# GA-Hub v1.1.5

## 更新下载
- Windows 上的 GitHub Release 查询、校验清单与安装包下载优先使用已启用的系统代理，避免仅有 HTTP_PROXY 环境变量时遮蔽系统 HTTPS 代理。
- 对下载重定向逐跳应用系统代理及代理绕过规则；保持 HTTPS、下载域名白名单、大小限制和 SHA-256 校验。
- 未配置静态系统代理时保持原有环境代理行为；本次不新增 PAC/WPAD 支持。

## 设置
- 新增独立「更新」标签，集中展示当前版本、检查新版、下载准备、预检与确认更新。
- 「远程连接」仅保留远程连接相关设置，不再混放更新面板。

## 安装与升级
下载 `GA-Hub-1.1.5-windows-x64.zip`，完整解压后运行 `ga-hub-desktop.exe`，保持桌面程序、后端、更新助手及元数据在同一目录。

旧版的代理选择问题不会因新版发布而自动修复：若旧版仍无法下载，请临时为其启动环境同时设置 HTTPS_PROXY，或手动下载此版本。升级至此版后，后续更新会采用修复后的系统代理逻辑。
