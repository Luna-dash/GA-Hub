# GA-Hub v1.1.6

## 会话管理
- 调整项目标题与会话行的间距，项目标题右侧按「置顶 / 展开全部 / 会话数」排列；操作按钮悬停或键盘聚焦时显示，触屏保持可用。
- 对齐项目会话数与会话删除按钮，隐藏操作时保留占位，避免布局跳动。
- 修复当前会话激活后删除按钮常驻显示的问题：桌面上仅悬停或键盘聚焦删除按钮时显示，鼠标移出后隐藏；触屏保留删除入口。

## 更新设置
- 高级本地导入的 SHA-256 改为选填：留空时自动计算归档哈希，填写时仍严格校验；可信来源确认及包内程序校验保留。
- 改善更新页文字对比度，避免浅黄高亮文字难以辨认。

## 安装与升级
下载 `GA-Hub-1.1.6-windows-x64.zip`，完整解压后运行 `ga-hub-desktop.exe`，保持桌面程序、后端、更新助手及元数据在同一目录。

已部署支持 Release 更新的版本，可在「设置 → 更新」中检查新版、下载并通过预检后确认升级。
