# Gyra v1.3.3（原 GA-Hub）

## 更新与桌面

- 修复 Windows 在线更新时，更新助手可能随旧后台进程一起退出的问题；同时补充更新切换日志，便于排查失败。

## Agy 与用量统计

- 更新 Agy 的 ACP 模型列表，移除旧模型选项；新会话默认使用「接受编辑」模式并自动响应权限请求。
- 用量统计页可切换查看全部、GA 或 Agy 的数据；调整 Agy 配额进度条及用量图表配色。

## MyKey 同步

- 可在本地设置中配置同步服务器 URL；自动同步默认关闭，需要时可手动开启。

## Windows x64 安装与升级

- 在线升级：打开「设置 → 更新」，下载新版并完成校验后，点击「立即重启并更新」。如果旧版无法完成自动切换，请下载 ZIP 手动安装。
- 手动安装：下载 `GA-Hub-1.3.3-windows-x64.zip`，可用 `SHA256SUMS.txt` 校验。完整解压后运行 `ga-hub-desktop.exe`，不要只替换主 EXE。
- 首次安装请按提示选择本机 GenericAgent（GA）目录和 Python 解释器。便携包不包含 GA 核心、Agy CLI 或账号凭据。
