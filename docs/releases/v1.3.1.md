# Gyra v1.3.1（原 GA-Hub）

## 更新与桌面

- 修复「设置 → 更新」导入本地 ZIP 后仍显示旧路径的问题。导入成功会清空表单；已有候选时，可点「取消旧候选并更换本地包」再导入，不会删除原始 ZIP。
- 修复旧更新状态残留，改进桌面更新的切换和启动健康检查。
- 补齐 Windows 便携包中文件管理所需的 COM 依赖。

## 界面与交互

- 改进键盘导航、弹窗焦点恢复、按钮状态和深色主题对比度。
- 为未保存的编辑和破坏性操作补充确认，统一错误提示和重试入口。
- 统一 Chat 和 Agy 的消息视区定位，改进输入法确认键处理和长会话返回底部操作。

## Windows x64 安装与升级

- 已支持在线更新的版本：打开「设置 → 更新」，检查并下载新版，校验通过后点击「立即重启并更新」。
- 手动安装：下载 `GA-Hub-1.3.1-windows-x64.zip`，可用 `SHA256SUMS.txt` 校验。完整解压后运行 `ga-hub-desktop.exe`；请保留 `sidecar/` 目录、更新助手和构建元数据，不要只替换主 EXE。
- 首次安装需按提示选择本机的 GenericAgent（GA）目录和 Python 解释器。安装包不包含 GA 核心、Agy CLI 或账号凭据。
