# GA-Hub v1.0.0

首次规范化正式版本发布，包含当前 main 的全部既有功能及以下修复。

## 修复
- 聊天运行时仍可创建定时任务，定时与指纹按钮统一为 44×44px 圆形按钮。
- Windows 便携包显式内置 rich / rich.cells，并加入冻结后端自检，修复换机后后端缺少 rich 的问题。

## 版本与发布
- Python、WebUI、Tauri/Rust、后端 API 及锁文件统一为 1.0.0。
- pyproject.toml 为版本权威源；提供同步脚本及 CI 一致性校验。
- 正式标签驱动 GitHub Release，附 Windows x64 便携 ZIP、build-info.json 与 SHA256SUMS.txt。
- 附源码提交号、构建时间及 EXE 哈希，方便定位与回退。

## 使用与升级
1. 下载 GA-Hub-1.0.0-windows-x64.zip，完整解压到独立目录。
2. ga-hub-desktop.exe 与 ga-hub-sidecar.exe 必须保持在同一目录。
3. 退出旧实例后运行 ga-hub-desktop.exe；升级前备份数据，不要覆盖运行中的程序。
4. Hub 后端已内置，但 GenericAgent 核心目录与解释器仍需按设置向导配置；本包不包含 GA 核心仓库。

这是 Windows x64 便携版，不是安装包；本次不引入自动更新或数据格式迁移。
