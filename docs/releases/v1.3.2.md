# Gyra v1.3.2（原 GA-Hub）

此版本包含原计划随 v1.3.1 发布的修复；v1.3.1 未生成正式安装包。

## 更新与桌面

- 修复「设置 → 更新」导入本地 ZIP 后仍显示旧路径的问题。导入成功会清空表单；可取消旧候选并重新选择本地包，不会删除原始 ZIP。
- 修复旧更新状态残留，改进桌面更新切换和启动健康检查。
- 补齐 Windows 便携包中文件管理所需的 COM 依赖。

## Agy 与界面

- Agy 的令牌及费用统计纳入嵌套子代理用量。
- 主模型和 Agy 模型选择器改为紧凑的固定宽度下拉布局。
- 修复远程页面按钮默认可能触发表单提交的问题。
- 改进弹窗焦点恢复、键盘导航、错误提示和长会话滚动体验。

## Windows x64 安装与升级

- 在线升级：打开「设置 → 更新」，下载新版并完成校验后，点击「立即重启并更新」。
- 手动安装：下载 `GA-Hub-1.3.2-windows-x64.zip`，可用 `SHA256SUMS.txt` 校验。完整解压后运行 `ga-hub-desktop.exe`，请勿只替换主 EXE。
- 首次安装请按提示选择本机 GenericAgent（GA）目录和 Python 解释器。安装包不包含 GA 核心、Agy CLI 或账号凭据。
