Production sidecar staging directory. Do not build by hand: use the unified entry `build_all.bat` / `python scripts/build_all.py` (see `docs/BUILD.md`); `npm run desktop:build` is intentionally disabled. `build_all` runs `desktop/build_sidecar.py --target <rust-target-triple>` and then Tauri validates and bundles the target-specific executable through `externalBin`. Generated executables are ignored.
